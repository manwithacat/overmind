# Deployment: Prerequisites

Required before beginning Phase 1. See [Deployment Strategy](strategy.md) for approach options.

## Infrastructure (Mail Tier — always required)

The mail server cannot run on standard PaaS (Heroku, Railway, Render) due to port and IP requirements. It needs a VPS or dedicated server, or Fly.io with dedicated IP.

- [ ] VPS or dedicated server with **static IPv4 address** — essential for PTR/rDNS
  - Recommended: Hetzner, OVH, Vultr (good mail IP reputation, easy PTR setup)
  - Avoid for mail: AWS EC2, GCP, Azure (port 25 blocked by default)
- [ ] PTR (reverse DNS) record for VM's IP pointing to mail hostname — **required for delivery reputation**
- [ ] Firewall open on ports:
  - 25 (SMTP)
  - 587 (submission)
  - 993 (IMAPS)
  - 443 (HTTPS)

## DNS

- [ ] Domain name with DNS management access (Cloudflare recommended for API-based record automation)
- [ ] MX record pointing to mail hostname
- [ ] SPF TXT record
- [ ] DKIM TXT record (generated by Stalwart)
- [ ] DMARC TXT record

## GPU (for LLM inference)

- [ ] CUDA 12.x driver installed (Ollama supports CUDA 11.8+ but 12.x recommended)
- [ ] Minimum 8GB VRAM for Mistral 7B Q4, or CPU-only for sub-50 user deployments

## Networking

- [ ] Separate IP or subdomain for web client and intelligence dashboard — recommended to avoid conflating webmail reputation with mail server reputation
